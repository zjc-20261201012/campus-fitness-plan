# campus-fitness-plan
校园健身训练计划分享平台
## 组员分工

- 张景程(A)：架构、数据库、登录鉴权、路由守卫、联调、部署
- 汤维城(B)：训练计划发布/列表/搜索分页、图片上传
- 柳欣浩(C)：后台管理：审核、分类维护、用户启用禁用
- 符宇弘(D)：统计看板、收藏、原型、报告、测试

## 环境要求

- Node.js 18+
- npm 9+
- Git

## 快速启动

1. 克隆仓库
   git clone https://github.com/zjc-20261201012/campus-fitness-plan.git

2. 进入目录
   cd campus-fitness-plan

3. 安装依赖
   npm install

4. 启动项目
   npm run dev

5. 浏览器访问
   http://localhost:5173
